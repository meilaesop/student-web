# Student Web

一个用于前端学习练习的静态网页项目，专注于 HTML、CSS 和 JavaScript 的基础应用。

## 项目简介

这个项目从零开始搭建一个“Web 学习打卡”页面，涵盖以下内容：

- 结构化页面布局
- 统一样式和主题切换
- 交互事件处理
- 本地存储与笔记保存
- 学习记录与复盘

## 学习目标

- 理解 HTML 的结构语义
- 学习 CSS 的布局与样式管理
- 掌握 JavaScript 的事件监听和 DOM 操作
- 练习使用 localStorage 保存页面状态
- 建立持续记录学习内容的习惯

## 项目结构

- `index.html`：页面主体结构
- `style.css`：页面样式与深浅色主题
- `script.js`：交互逻辑与本地存储
- `day01-notes.md`：Day 01 学习笔记
- `day02-notes.md`：Day 02 学习笔记
- `web-development-setup.txt`：开发环境说明

## 运行方式

### 方法 1：直接打开

1. 在项目文件夹中找到 `index.html`
2. 双击打开即可在浏览器中查看效果

### 方法 2：使用本地服务器

如果你想模拟真实开发环境，可以使用本地静态服务器，例如：

```bash
python -m http.server 8000
```

然后在浏览器访问：

```bash
http://localhost:8000
```

## 当前功能

- 今日学习打卡
- 深浅色主题切换
- 学习笔记输入与保存
- 记录用户已完成状态

## 说明

这是一个适合初学者练手的前端项目，重点不是“炫酷效果”，而是理解三者之间的关系：

- HTML：决定页面内容和结构
- CSS：决定页面样式和表现
- JavaScript：让页面具有交互和动态更新

持续写代码、持续记录，才是真正的学习方式。
