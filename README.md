# Student Web

这是一个用于学习 HTML、CSS 和 JavaScript 的前端练习项目，主要展示了：

- 网页结构搭建
- CSS 样式与主题切换
- JavaScript 交互逻辑
- 学习打卡与笔记保存

## 项目内容

- `index.html`：页面结构
- `style.css`：页面样式与深浅色主题
- `script.js`：页面交互与本地存储逻辑
- `day01-notes.md`：Day 01 学习笔记
- `day02-notes.md`：Day 02 学习笔记

## 运行方式

1. 打开项目文件夹
2. 直接双击 `index.html` 打开浏览器
3. 或使用本地开发服务器预览

## 学习目标

- 理解网页三件套：HTML、CSS、JavaScript
- 学会使用 JavaScript 处理交互事件
- 练习本地存储与状态保持
- 形成持续学习和记录的习惯

## 说明

这个项目用于前端入门练习，适合初学者边做边学。重点是理解页面结构、样式控制和行为逻辑之间的关系。
