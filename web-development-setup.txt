排错顺序：
1) 报错"无法将 xxx 项识别为 cmdlet" → 先重启 VS Code（多数是终端会话过期）。
2) 重启后仍报错 → 用 where.exe 定位：
     where.exe git
     where.exe python
     where.exe node
   若 where 找不到 → 执行第四节配置 PATH。
3) 特例：若 python --version 无任何输出，或 where.exe python 第一条指向
   C:\Users\<用户>\AppData\Local\Microsoft\WindowsApps\python.exe（0 字节占位符），
   说明命中了 Windows"应用执行别名"。
   处理（二选一，推荐 a）：
   a) 设置 → 应用 → 高级应用设置 → 应用执行别名，关闭 python.exe / python3.exe；
   b) 将 D:\Python 在 PATH 中前置（见第四节修正脚本）。


四、PATH 配置（仅重启后 where 仍找不到时才需要 · 修正版）
写入用户级变量，避免动系统级；且把 D:\Python 前置以避开 WindowsApps 占位符：
  $paths = "D:\Python","D:\Python\Scripts","D:\Git\cmd","D:\nodejs"
  $cur = [Environment]::GetEnvironmentVariable("Path","User")
  $cur = if ($null -eq $cur) { "" } else { $cur }
  $list = @($cur.Split(';') | Where-Object { $_ -ne '' -and ($paths -notcontains $_) })
  $new  = (@($paths) + $list) -join ';'
  [Environment]::SetEnvironmentVariable("Path", $new, "User")
执行后重启 VS Code，用以下命令验证（关键看第一条命中）：
  where.exe git      # 期望 D:\Git\cmd\git.exe
  where.exe python   # 期望 D:\Python\python.exe（不能是 WindowsApps）
