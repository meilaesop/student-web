2. 配置 Windows 用户 PATH（详细步骤）

【先判断：是真没配，还是只是没生效？】
命令行敲 git / python / node 时，Windows 会去“用户环境变量 PATH”里逐目录查找对应的 .exe。
报错“无法将 git 项识别为 cmdlet…”有两种可能：
  (a) PATH 里确实没有 D:\Git\cmd —— 需要添加（见下方）。
  (b) PATH 里已有，但当前终端是“更新之前”打开的旧会话 —— 只需重开终端。
先重开一个全新终端再试；仍不行才按下面步骤添加。
用完整路径判断 Git 是否本身没问题：
  & "D:\Git\cmd\git.exe" --version

【需要加入 PATH 的目录】
- D:\Git\cmd
- D:\Python
- D:\Python\Scripts
- D:\nodejs

【方法 A：图形界面（推荐初学者，最稳）】
1. 按 Win 键，搜索“环境变量”，打开“编辑账户的环境变量”。
2. 在弹出的“环境变量”窗口上半部分（用户变量）中，选中 “Path”，点“编辑”。
3. 在“编辑环境变量”窗口里点“新建”，逐条加入下面 4 条（一条一个框）：
   - D:\Git\cmd
   - D:\Python
   - D:\Python\Scripts
   - D:\nodejs
4. 如列表里已存在相同路径，就不要重复添加（避免重复路径导致命令冲突）。
5. 一路点“确定”保存，不要点“取消”。
6. 关闭所有已打开的终端窗口，重新打开（或重载 VS Code），让新 PATH 生效。

【方法 B：PowerShell 命令行（进阶，一次执行）】
用当前用户级变量写入，避免动到系统级变量：
  $paths = "D:\Git\cmd","D:\Python","D:\Python\Scripts","D:\nodejs"
  $cur = [Environment]::GetEnvironmentVariable("Path","User")
  $list = $cur.Split(';') | Where-Object { $_ -ne '' }
  foreach ($p in $paths) {
      if ($list -notcontains $p) { $list += $p }
  }
  [Environment]::SetEnvironmentVariable("Path", ($list -join ';'), "User")
执行后重开终端，再用 where git 验证。

【验证是否生效】
重新打开终端后执行：
- where git      （应输出 D:\Git\cmd\git.exe）
- git --version  （应输出版本号，如 git version 2.55.0.windows.5）

【本机实测记录（重要）】
- Git 已安装：D:\Git\cmd\git.exe，版本 2.55.0.windows.5
- 用户变量 Path 中已包含：C:\Users\Administrator\AppData\Local\Microsoft\WindowsApps; D:\Git\cmd; D:\Python; D:\Python\Scripts; D:\nodejs
- 用完整路径 & "D:\Git\cmd\git.exe" --version 可正常运行
- 结论：PATH 本身已配置正确。之前 git 命令报错，是“终端会话过期”导致，
  即终端在 PATH 写入之前就已打开，没读到新值。重开终端后 git --version 正常。
- 因此：正常情况下无需再改 PATH，先重开终端 / 重载 VS Code 即可。

六、常见问题排查
如果命令报错，优先检查：
- PATH 中是否包含 D:\Git\cmd、D:\Python、D:\Python\Scripts、D:\nodejs
- 是否需要重开终端或重载 VS Code
- 是否用的是当前用户级环境变量，而不是系统级变量
- 是否有重复路径导致命令冲突

可以用以下命令快速排查：
- where git
- where python
- where node
- where npm

【专项：git 命令无法识别】
现象：PowerShell 报“git : 无法将“git”项识别为 cmdlet、函数、脚本文件或可运行程序的名称”。
原因分两种，按顺序排查：
  1. 最可能：终端会话过期（PATH 已配好，但终端是更新前打开的）。→ 关闭并重开终端，或重载 VS Code 窗口。
  2. 其次：PATH 里确实没有 D:\Git\cmd。→ 按第 2 步添加。
定位（用完整路径应能成功，说明 Git 本身没问题）：
  & "D:\Git\cmd\git.exe" --version
确认 PATH 是否已含该目录（只读，不改动）：
  [Environment]::GetEnvironmentVariable("Path","User")
  where git
修复：
  1. 先重开终端；仍不行，再按第 2 步把 D:\Git\cmd 加入“用户变量 Path”；
  2. 重开后用 where git 确认已指向 D:\Git\cmd\git.exe。
本机结论：PATH 已正确，重开终端即可，无需再改。
临时绕过（不改 PATH 时）：
  在所有 git 命令前用完整路径，例如：
  & "D:\Git\cmd\git.exe" -C "D:\Microsoft VS Code\student-web" status
